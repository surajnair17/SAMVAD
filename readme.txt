# Samvad - Real-Time Speech Translator

Samvad is a real-time speech translation system that converts Hindi speech into English using AI.

## Features

* Speech-to-text using Whisper
* Automatic language detection
* Hindi to English translation
* Voice output (text-to-speech)

## Tech Stack

* Python
* OpenAI Whisper
* Google Translate API
* Pyttsx3
* SoundDevice

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python main.py
